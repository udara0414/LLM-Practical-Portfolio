# Lab 05 – RAG Pipeline

## Overview

This project demonstrates the implementation of a Retrieval-Augmented Generation (RAG) pipeline using Large Language Models.

## Technologies Used

- Python
- LangChain
- ChromaDB
- Ollama
- Streamlit

## Main Features

- PDF document loading
- Text chunking
- Text embeddings
- ChromaDB vector storage
- Document retrieval
- LLM-based question answering
- PDF document upload

## Project Structure

- `notebooks/` – Practical notebooks
- `screenshots/` – Project screenshots
- `README.md` – Project documentation
