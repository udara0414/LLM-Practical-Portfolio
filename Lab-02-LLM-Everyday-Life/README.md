# Lab 02 – AI in Everyday Challenges

## Group 4 – The Dehydrated Student

### Module
PUSL 3205 – Large Language Models and Generative AI

### Project Overview
This project focuses on developing an innovative AI-supported product that encourages students to maintain healthy hydration habits throughout the day.

### Objective
To use Large Language Models (LLMs) as product-development partners to identify an everyday student challenge and develop a creative solution.
