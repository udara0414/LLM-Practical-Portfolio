# Lab 04 – Fine-Tuning an LLM using LoRA/QLoRA

## Overview

This practical focuses on fine-tuning a small
instruction-tuned Large Language Model using
Parameter-Efficient Fine-Tuning (PEFT).

## Objectives

- Install the required libraries.
- Check GPU availability.
- Select a suitable pre-trained language model.
- Create a domain-specific Q&A dataset.
- Configure LoRA or QLoRA.
- Fine-tune the model using SFTTrainer.
- Evaluate and compare the original and fine-tuned models.

## Tools and Technologies

- Python
- Hugging Face Transformers
- Hugging Face Datasets
- PEFT
- TRL
- Accelerate
- BitsAndBytes
- Google Colab
